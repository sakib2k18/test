# Bus Portfolio — PHP + MySQL (XAMPP)

This workspace has been converted to a UI-only prototype. Database, authentication, and admin CRUD have been removed — the site now serves static/sample bus data and a responsive UI.

Quick start
1. Start Apache (XAMPP) and open: http://localhost/test/

Notes
- The site no longer requires MySQL. Pages are pre-populated with sample data. To re-enable DB and auth later, restore the removed files from version control and add a `config.php` with DB credentials.
- Uploaded images (sample placeholders) live in `assets/uploads/`. Add your own images there and update paths in `index.php` or `bus.php`.

If you want, I can:
- Reintroduce a lightweight JSON-based data backend instead of MySQL, or
- Restore full DB-backed CRUD and walk you through fixing MariaDB issues.
